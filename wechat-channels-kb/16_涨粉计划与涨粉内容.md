# 16 涨粉计划与涨粉内容（10 → 100 → 1000 有效关注）

> 整理日期：2026-10-21
> 适用：你的情况，即达人带货、用 AI 辅助制作、没有实物、当前约 10 个关注。
> **依据分两类**：
> - 平台规则【官方】：门槛、低质量判定、原创、AI 标识、不刷粉，来源见 02、10、15
> - 计划结构、比例、节奏、示例【主观判断】：没有平台数据支撑，要用你自己的数据验证、调整
>
> **不预测"几周涨到多少粉"**：没有可靠依据。计划里只设"做到什么动作"和"看什么数据"。

---

## 一、先定 4 件事（写计划前必须有答案）

| # | 要定的事 | 怎么定 | 你的答案 |
|---|---|---|---|
| 1 | **一个方向**（品类） | 选一个以后要带货的"参数类"品类（13）；在带货助手选品中心确认有足够多的商品可带 | |
| 2 | **一句话定位** | 模板：`我是【谁】，专门分享【什么人】的【什么问题】怎么解决` | |
| 3 | **出镜方式** | 至少选一种：露脸口播 / 本人声音 + 手部操作 / 本人声音 + 真实场景实拍。**不能只用 AI 图片配特效**（官方低质量细则，见 15） | |
| 4 | **每周能稳定发几条** | 宁少勿断。建议 3~5 条 | |

> **涨粉阶段不需要商品实物**：拍的是"知识 + 场景 + 方法"，可以用你家里已有的东西、你自己的生活场景来演示。到能挂车之后，再换成具体商品。【主观判断】

## 二、涨粉的底层逻辑（视频号）

| 机制 | 内容 | 依据 |
|---|---|---|
| 有效关注才算数 | 不含可疑或刷量用户、不含当天新增；刷粉不计入门槛，还可能违规 | 官方【中-高】 |
| 官方鼓励的内容 | 原创真实；提供"有用、共鸣、幻想、好奇、思考"之一；制作精良（清晰、配音、字幕）；重视封面、标题、开头 10 秒 | 官方创作指引【中】 |
| 会被判低质量 | 视频过短、只有文字或 PPT、多张图片加简单特效拼凑、长时间无真人出镜、重复发布相似内容 | 官方低质量细则、宣传规范【中】 |
| 原创 | 纯图片轮播质量不高；原创一般应为真人出镜实拍 | 官方原创须知【中】 |
| AI 内容 | AI 合成的非真实音视频要显著标识 | 官方运营规范【中-高】 |
| 社交分发 | 内容先在好友圈层传播、数据好了再进更大推荐池（第三方说法，官方未公开算法） | 第三方【低-中】 |

**推出来的做法**【AI推断】：
1. 每条都给一个**关注理由**：看完觉得"这个号以后还有用"
2. 做**系列**：让人想看下一集
3. **真实**：有你本人的声音和动作，AI 只作辅助并标注
4. 冷启动靠**真实好友**看和转，不靠互粉

## 三、内容结构：3 类内容 + 比例【主观判断】

| 类型 | 作用 | 占比（建议） | 形式示例 |
|---|---|---|---|
| **A 干货 / 避坑**（"有用"） | 带来关注的主力 | 约 60% | 3 个坑、选购要看哪 3 点、常见误区 |
| **B 系列教程**（"想看下一集"） | 留住关注、提升主页价值 | 约 30% | 「XX 改造第 1/2/3 天」「每周一个 XX 方法」，放进合集 |
| **C 互动 / 答疑**（"共鸣、参与"） | 提高评论，增强信任 | 约 10% | 回答真实评论、"你家是哪种情况？" |

- 3 类都**不挂商品**（10 粉也挂不了）。
- 系列用合集归档（合集管理是零粉权益，见 10）。

## 四、单条涨粉视频的结构（30~60 秒，主观建议）

| 段落 | 时长 | 做什么 | 规则提醒 |
|---|---|---|---|
| ① 开头 | 0~10 秒 | 第一句点出**人群 + 问题**；第一个画面是真实场景或真人操作 | 官方重视开头 10 秒 |
| ② 展开 | 10~40 秒 | 讲 1~3 个具体方法，每个都配**真实演示**；AI 画面只作示意 | 不做图片拼凑 |
| ③ 收尾 | 最后 5~10 秒 | 给关注理由（"下一集讲 XX"）+ 抛一个好回答的问题 | 不留联系方式 |
| 标题 | — | 人群词 + 问题词 | 不用"最""第一" |
| 封面 | — | 大字写清"这条解决什么" | — |
| 发布 | — | 声明原创（确实是自己拍的）；含 AI 合成内容就加 AI 标注；加入对应合集 | 官方原创、AI 标识规则 |

### 官方原文补充（2026-10-21，见 18）
- **不能用奖励诱导互动**：《运营规范》4.4.1 原文禁止"利诱用户进行分享、关注、点赞和评论"，例如"集赞""分享可增加一次抽奖机会"。结尾只能真诚提问，不能"点赞送礼""关注抽奖"。
- **不能批量做相似内容**：5.12 禁止"批量发布通过近似的情景、文案、元素等编造的同质化内容"。
- **原创**：涨粉阶段的非带货视频，自己真人实拍的可以声明原创；以销售为主要目的的带货视频不得声明原创。
- **账号名称**：不能用"正能量、吃货、健康、养生、百科"这类通用词单独作名称（3.6.7）。

### 发布前自检（涨粉版）
- [ ] 有真人元素（声音、出镜或手部操作），不是纯图片 / 纯 AI
- [ ] 不是图片 + 简单特效拼凑，也不是文字 / PPT 播放
- [ ] 时长不过短（具体下限官方没公布数字，建议 ≥ 20 秒且信息完整）【主观判断】
- [ ] 开头 10 秒内说清"给谁看、解决什么"
- [ ] 有字幕、画面清晰
- [ ] 和最近发的视频不雷同（避免"重复发布相似内容"）
- [ ] AI 合成内容已标注
- [ ] 结尾有关注理由 + 一个问题
- [ ] 没有联系方式、二维码、外链
- [ ] 没有"点赞送礼""关注抽奖"之类的诱导互动

## 五、4 周涨粉计划（第一轮）

### 第 0 周：准备（2~3 天）
- [ ] 填完第一节的 4 件事
- [ ] 改头像、名字、简介，让简介体现一句话定位
- [ ] 建 1~2 个合集（如"XX 避坑""XX 改造系列"）
- [ ] 用 11 章的方法拆解 5 条同方向爆款 + 2 条对照，记下开头第一句话
- [ ] 列 20 个选题（用"人群 + 场景 + 问题"公式），按 A/B/C 分类

### 第 1~4 周：每周固定节奏
| 时间 | 动作 |
|---|---|
| 周一 | 定本周 3~5 个选题（A 类 2~3 条，B 类 1~2 条，C 类 0~1 条），写口播稿 |
| 周二~周日 | 按节奏拍摄、发布；每条发布后 24h、72h 记录数据（09 模板） |
| 每天 10 分钟 | 回复所有评论；把好问题记到"C 类选题池" |
| 发布当天 | 发给 3~5 个**真实**会看的好友或群，请他们看完觉得有用再点赞、转发（不要求、不交换互赞） |
| 周日 30 分钟 | 复盘：本周哪条最好？好在哪一项（开头 / 选题 / 形式）？下周**只改一个变量** |

### 每周复盘看的数据（视频号助手 → 数据中心）
| 指标 | 用途 |
|---|---|
| 每条 24h 播放 | 和自己账号的中位数比，不和别人比 |
| 每条带来的关注数 | **最关键**：判断哪类内容真的涨粉 |
| 评论数 | 判断互动设计是否有效 |
| 转发数 | 判断内容是否"值得发给别人" |

> 数据中心各指标的口径，以后台说明为准（本库未核实）。

### 第 4 周末的检查点
| 检查项 | 标准 |
|---|---|
| 发布稳定 | 4 周都达到自己定的周更数 |
| 合规 | 没有收到违规通知 |
| 找到有效内容 | 能说出"哪一类 / 哪种开头"带来的关注明显更多 |
| 关注 | 记录实际有效关注数（不设硬目标） |

**没起色时按顺序调整**（每次只改一项，测 3 条）：开头第一句 → 标题人群词 → 出镜程度（加露脸）→ 选题角度 → 发布时间段。同一方向调满 3 项再考虑换方向。

## 六、到达门槛后的动作

| 达到 | 动作 | 依据 |
|---|---|---|
| 100 有效关注 | 带货权限页确认**直播带货**；愿意的话开**真人**直播（数字人直播大概率不行） | 官方带货账号体系、13 |

| 1000 有效关注 | 开通短视频挂车；把涨粉期效果最好的内容结构改成带货版，发表时挂商品 + AI 标注 | 官方创作指引、15 |

## 七、示例：以"家居收纳"为方向（仅为演示怎么填，不是推荐）

> 这只是演示，方向要你自己定。"家居收纳"是 13 章提到的参数类品类之一，选它不代表它在视频号上更容易涨粉。

- **一句话定位**：我是一个租房 5 年的普通人，专门分享小户型、租房党的收纳问题怎么解决。
- **出镜方式**：本人声音 + 手部操作 + 自己家的真实场景；AI 只用来做片头和"整理前后示意图"，并标注 AI。
- **A 类选题示例**：
  - 租房党买收纳盒之前，先量这 3 个尺寸
  - 衣柜越收越乱？问题可能出在这一步
  - 厨房台面堆满东西，先别急着买置物架
- **B 类系列**：「出租屋 7 天收纳改造」第 1~7 天，放进同一个合集
- **C 类**：上条视频有人问"转角柜怎么用"，统一回答

**一条 A 类视频的分镜示例**

| 时间 | 画面 | 字幕 / 配音 |
|---|---|---|
| 0~5 秒 | 真实拍摄：手拿卷尺量柜子 | 租房党买收纳盒之前，先量这 3 个尺寸 |
| 5~15 秒 | 手部特写：量柜子内部宽度 | 第一个，内宽，不是外宽，差 2 厘米就塞不进去 |
| 15~25 秒 | 手部特写：量深度、高度 | 第二个深度，第三个层板到顶的高度 |
| 25~35 秒 | AI 示意图（已标注）：尺寸对不上的盒子塞不进去 | 很多人买回来才发现放不进去，就是漏量了一个 |
| 35~45 秒 | 真实画面：量好的尺寸写在便签上 | 量完写下来，买的时候对着看。下一条讲怎么按尺寸选盒子。你家哪个柜子最难收？评论区说说 |
