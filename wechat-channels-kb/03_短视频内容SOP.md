# 03 短视频内容 SOP

> 来源：原始资料《03_新手内容落地SOP》，正文**原样保留**（只去掉了原标题）。核验意见统一放在文末「🔍核验与标注」。
> 标签：除注明"官方原文"的部分外，正文里的方法论都属于原资料作者的经验做法【原始资料 / 主观判断】，不是平台规则。

**这份文件解决你最大的问题：内容不知道该怎么落地。**

## 一、先纠正一个误区

新手以为带货视频要"创意"、"要爆"。

**错。** 带货视频是一套流水线，是填空题，不是创作题。

你的任务不是想创意，是：
1. 找 3 个同类账号
2. 抄他们的**结构**（不是抄内容）
3. 换成你的商品和场景
4. 重复

---

## 二、第一步：找对标（一次做完，管用半年）

**怎么找**：
1. 打开视频号，搜你品类关键词（比如"红糖""母婴""防晒"）
2. 只看**最近 30 天**发过、**点赞过千**的视频
3. 挑 3~5 个账号，把它们的带货视频挨个看一遍

**看什么（重点）**：
- 开头 3 秒说了什么话
- 前 10 秒画面是什么
- 商品在第几秒出现
- 结尾怎么催单
- 一条视频多长

**动作**：建个表格或记事本，把 20 条视频的"开头第一句话"抄下来。这就是你的素材库。

---

## 三、第二步：内容模板（直接套）

### 30~45 秒带货短视频标准结构

| 位置 | 时长 | 干什么 | 举例 |
|---|---|---|---|
| ① 钩子 | 0-3秒 | 一句话戳中人群+痛点 | "一到夏天就流汗脱妆的姐妹，看这里" |
| ② 共鸣 | 3-8秒 | 描述场景，让人点头 | "我自己就是油皮，中午妆就花了" |
| ③ 铺垫 | 8-15秒 | 你试过什么、踩过什么坑 | "试了好几款都不行，直到…" |
| ④ 种草 | 15-30秒 | 商品 + **可核实的具体卖点** | "这个持妆 8 小时，SPF50+，成膜快" |
| ⑤ 催单 | 30-40秒 | 给下单理由 + 引导橱窗 | "左下角小黄车，今天有券" |

### 前 3 秒钩子公式（选一个用）

- **人群 + 痛点**：`一到XX就XX的人，看这条`
- **身份代入**：`家里有XX的，别划走`
- **反常识**：`别再XX了，我一直都做错了`
- **数字**：`3个XX的坑，我踩了2年`
- **对比**：`这是我用之前/之后`

### 官方对"好视频"的定义（照着对齐就不会跑偏）

官方《商品分享视频创作指引》里的原话，拆成可执行动作：

| 官方要求 | 你的动作 |
|---|---|
| 原创真实 | 自己出镜，用自己拍的画面 |
| 提供获得感/情绪价值（有用/共鸣/幻想/好奇/思考） | 每条视频至少回答一个"这对我有什么用" |
| 制作精良：画质清晰、BGM 有带入感、有必要配音和字幕 | 用手机横屏或竖屏拍，**一定加字幕** |
| 注重封面、标题、开头 10 秒 | 封面写大字，标题带人群词 |
| 真人出镜 + 真实场景 | 站在你的真实使用场景里拍 |
| 结合痛点场景 | 见下面第四节 |
| 真诚分享商品信息 | 说清材质/成分/用法/适用人群 |
| 有价值的商品信息（基础信息+核心卖点+领域知识） | 每条讲透 1~2 个点，不要面面俱到 |

## 四、第三步：痛点场景对照表（官方给的素材，直接用）

官方按品类给了痛点场景，抄下来改成你的：

| 品类 | 官方给的方向 |
|---|---|
| 美食/食品/生鲜/酒类/营养品/厨具 | 美食教程、食材选购/保鲜/处理技巧、好物推荐、开箱测评、吃播、美食知识科普、饮食搭配、健康理念、美食攻略、探店 |
| 亲子/食品/图书/玩具/母婴/家居日用 | 知识科普、亲子日常、育儿经验、教育理念、好物推荐、美食教程、开箱测评 |
| 知识/科普/图书/学习工具/办公用品 | 知识科普、经验分享、人物故事、好书推荐、好物推荐、开箱测评 |

**痛点场景对照**（官方举例）：
- 美妆个护 → 换季皮肤敏感 / 拯救夏季脱妆
- 服饰 → 夏季防晒透气 / 懒人轻松穿搭
- 食品 → 过节长辈送礼 / 健身控糖饱腹
- 家居 → 居家办公好物 / 小户型适用

**用法**：`人群` + `场景` + `痛点` + `商品` = 一条选题

> 例：`租房党` + `小厨房` + `没地方放东西` + `壁挂调料架`
> 例：`宝妈` + `宝宝挑食` + `营养不够` + `儿童营养品`

## 五、第四步：每条的固定生产流程（30分钟一条）

1. **定选题**（2分钟）：从上面的公式挑一个
2. **写口播**（8分钟）：用第三节模板填，字数控制在 **120~180 字**（约 40 秒）
3. **拍**（10分钟）：手机架好，真人出镜，一次拍 2~3 遍
4. **剪**（8分钟）：剪映自动识别字幕，删掉废话，加一个封面字
5. **发**（2分钟）：标题带人群词 + 发表时挂商品

**关键提醒（官方原文）**：商品**只能在发表时挂**，发出去就补不了。所以发之前确认商品选对。

---

## 六、发布时的 3 个固定动作

1. **标题**：人群词 + 痛点词，例：`油皮姐妹夏天必看`
2. **话题**：带 2~3 个品类话题
3. **商品**：选与视频内容**相关**的商品（官方明确要求相关性）

---

## 七、不要做的事（省你时间）

- ❌ 不要一条视频讲 5 个卖点 → 讲透 1~2 个
- ❌ 不要用假人/AI 素材堆时长 → 官方明确要真人真场景
- ❌ 不要凑时长、重复、慢放 → 没流量
- ❌ 不要参考抖音的那套指标 → **视频号和抖音规则不一样，分开研究**
- ❌ 不要为了"完美"不发 → 先发 1 条跑通流程
