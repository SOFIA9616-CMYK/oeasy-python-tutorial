# Chatbox「搭档」填写说明（微信视频号）

格式参照你抖音搭档的做法：Prompt 栏只放一段短指令，让搭档每次先去读本地的入口文件 `00_先读这个.md`。

---

## 第 1 步：把资料包放到移动硬盘

把整个 `wechat-channels-kb` 文件夹复制到移动硬盘，并**改名**为：

```
/Volumes/T7 Shield/Chatbox资料包_微信视频号/
```

- 不要放进抖音那个 `Chatbox资料包` 文件夹里：两边都有 `00_先读这个.md`，会互相覆盖。
- 想换路径也可以，但下面 Prompt 里的路径要跟着改成一样的。

## 第 2 步：搭档设置这样填

| 栏位 | 内容 |
|---|---|
| 标题 | `视频号达人带货｜AI视频顾问` |
| 描述 | `我的微信视频号达人带货助手：只讲视频号/微信小店规则，负责门槛核对、违规自检、AI带货视频脚本、爆款拆解和执行计划。` |
| 搭档记忆 | 打开 |

**Prompt 内容**（整段复制）：

```
你是"视频号带货顾问"，只做微信视频号/微信小店达人带货的脚本和规则搭档，不讲其他平台。
每次开始，先读这个本地文件，并严格照它执行：
/Volumes/T7 Shield/Chatbox资料包_微信视频号/00_先读这个.md
其他文件只在那份文件说需要时才读。读不到就直接说读不到，不要假装读过。
```

## 第 3 步：测试能不能读到文件

保存后新开一个对话，问它：

> 你读到 00_先读这个.md 了吗？里面说我挂商品需要多少有效关注？

- 正确回答：读到了；达人带货要 **1000 有效关注**，营业执照不能跳过。
- 如果它说读不到，或者答错了，说明 Chatbox 没有读取本地文件的权限，或者路径不对。这时改用**备用方案**：打开 `00_先读这个.md`，全选复制，直接粘贴到 Prompt 栏（约 6500 字，上限 4 万字）。备用方案只带入口文件的内容，其他 13 个文件它读不到。
