## 二、Word《抖老板产品手册》【原始资料：第三方工具说明】

### 是什么
第三方达人选品平台，支持**抖音、淘宝、快手**多账号，提供商品榜单、免费样品、订单统计、员工管理等功能。手册自称"200 万+ 带货达人、50 万+ 入驻机构"（第三方自述，**未核实**）。

### 和视频号相关的部分
- 支持**授权微信视频号账号**：网页版 → 工作台 → 切换到微信端 → 账号管理 → 立即授权，需要开通「微信开发者平台」权限后扫码授权。授权期限半年。
- 手册里的选品、高佣、橱窗升佣、订单同步说明**只写了抖音（精选联盟）和快手**。它在视频号上能做到什么，手册**没有说明**。

### 风险提示【AI推断】
| 功能 | 风险 |
|---|---|
| 账号授权 | 第三方会拿到账号数据权限。微信官方对此类授权的规则**尚未验证**。授权前请确认授权范围，不用时及时解除 |
| 去水印（粘贴抖音链接一键去水印） | 去掉他人作品的水印再发布，涉及侵权，也违背视频号"原创真实"的方向（见 03、05） |
| 文案提取 / AI 仿写 | 仿写他人爆款文案，有抄袭风险 |
| 素材库（商家提供的商品素材） | 手册自己也提醒"不做个性化修改可能违规" |
| 违禁词检测 | 可以作为辅助，但它检测的是第三方词库，**不等于**视频号的审核标准 |
| 领样作业：收样后 15 天内发视频或推广 3 单以上 | 这是抖老板和商家之间的约定，不是平台规则 |
