# 02 带货身份与开通条件

## 一、官方带货身份【外部核验】

据媒体报道，《微信小店带货账号体系管理规则》**自 2025-02-07 起施行**，视频号账号的带货身份简化为两类：

- **店铺自营**：账号为自己的微信小店带货
- **达人带货**：使用商品信息分享功能，通过橱窗、直播、短视频推广**其他微信小店**的商品，赚取达人佣金

来源：[电商派报道](https://www.pai.com.cn/p/01jkhsabz0zxxt5gxqjm0qggjt)、[官方规则页](https://support.weixin.qq.com/cgi-bin/mmsupportacctnodeweb-bin/pages/AGviPBXlrEiWBgxk)（官方页面未能直接打开）。置信度：中

## 二、两条路线对比【原始资料】

| | 路线 A：开店卖货（店铺自营） | 路线 B：带货赚佣金（达人带货） |
|---|---|---|
| 一句话说明 | 开自己的小店，卖自己的货 | 不囤货，帮别人卖，赚佣金 |
| 营业执照 | 需要 | 不需要（个人也能做） |
| 收入 | 商品利润 | 佣金（商品页标有比例） |
| 货源 | 自己找或自己有 | 在平台选品中心挑 |
| 适合谁 | 有稳定货源或能对接工厂 | 新手起步、没有货源 |

原资料的建议：**有营业执照就先走 A，再叠加 B**。理由是 A 不受"1000 粉"限制、利润更高，并且不要一开始就两条线同时铺开。【主观判断，来自原资料】

## 三、短视频挂商品的开通条件（关键）

### 官方条件【外部核验】置信度：中-高

官方《商品分享视频创作指引》的搜索摘要显示，满足以下 **3 个条件后权益自动开通**：

1. 视频号已**实名认证**；有效关注数 **≥ 1000**，**或**为微信小店**可对外展示的店铺自营账号**
2. 内容符合规范，**账号无违规**
3. **公开发表视频 ≥ 10 条**

- **有效关注数**：正常关注用户数，不含可疑或刷量用户，**也不含当天新增的关注**。
- **查看或申请**：视频号 → 创作者中心 → 带货中心 → 个人中心 → 带货权限
- 来源：[商品分享视频创作指引](https://support.weixin.qq.com/cgi-bin/mmsupportacctnodeweb-bin/pages/u18g0aVaQnH3neEC)

### 存在的冲突
- 微信开放社区有帖子引用《视频号的带货短视频发布指南》，说"有效关注数 ≥ 1000"与"拥有微信小店自营账号"满足**任一条件**即可，没有提 10 条视频（[开放社区帖](https://developers.weixin.qq.com/community/minihome/doc/000e6a96840bd822a3c35fefc61400)）。
- 本库按官方支持页面的三条件执行。**10 条视频按必需条件准备**，比较稳妥。

### 🔍核验：原资料需要修正的地方
- 原资料 02 第 3 步只写了"有店铺自营资质，不用凑 1000 粉"，**漏了"公开发表视频 ≥ 10 条"和"账号无违规"**。自营账号也必须满足这两条。
- 原资料《第一个可商业化内容方向研究》里写的"**100 粉 + 10 条视频后开通带货权限**"与上面的官方条件**不一致**。如果走达人路线挂短视频，门槛是 **1000 有效关注**。【外部核验】
- 有媒体提到，优选联盟里**公众号**带货需要粉丝数超过 100（[IT之家](https://www.ithome.com/0/799/475.htm)）。这是公众号的规则，不是视频号短视频的规则，"100 粉"的说法可能就是从这里混过来的。【AI推断】置信度：低

## 四、路线 A：开店步骤【原始资料】

### 第 1 步：开微信小店
- 入驻入口：https://channels.weixin.qq.com/shop/ssr/applyments/storeOpeningGuidelines
- 营业执照是公司 → **企业店**；营业执照是个体工商户 → **个体工商户店**

**需要准备的材料**

| 材料 | 企业店 | 个体店 |
|---|---|---|
| 已实名认证的微信号 | ✅ | ✅ |
| 营业执照 | 企业营业执照 | 个体工商户营业执照 |
| 法人 / 经营者身份证件 | ✅ | ✅ |
| 超级管理员身份证件 | ✅ | ✅ |
| 银行账户 | **必须对公**，名称与主体一致 | 对公、对私都可以 |

**原资料列出的 5 个高频驳回原因**（原资料称来自官方；本次未查到官方原文，第 5 条法律依据已核实，见下）
1. 营业执照注册号查不到：新执照需要约 5 天等工商系统同步
2. 证件用了截图、翻拍或模糊复印件：必须用彩色原件照片或扫描件
3. 复印件没盖公章：必须盖**红色鲜章**，电子章不行
4. 营业执照经营范围没有覆盖要卖的类目
5. 食品类资质选错："预包装食品销售备案凭证"和"食品经营许可证"不是一回事

建议用**电脑端**提交，有类目智能推荐。

🔍核验（2026-10-20）
- 第 5 条的法律依据：按《食品安全法》，**仅销售预包装食品**的，不需要取得食品经营许可，但要向所在地县级以上市场监管部门**备案**。所以"预包装食品销售备案"和"食品经营许可证"确实是两种不同的资质。【已核实事实】置信度：高
- 判断企业还是个体户：营业执照的「主体类型」一栏写明了。第三方说法是，统一社会信用代码以 91/93 开头的是企业，以 92 开头的是个体户（[第三方测评](https://www.ifanr.com/minapp/955288)）。以执照上写的主体类型为准。
- 第 1~4 条（5 天同步、彩色原件、红色鲜章等）本次**未查到官方原文**【尚未验证】，以驳回通知里写的原因为准。

### 第 2 步：上架商品，让店铺处于"可对外展示"状态
这是店铺自营账号获得短视频挂车资格的前提。

> 🔍核验：一份 2026-06 更新的官方 FAQ 摘要提到"完成小店入驻并**上架至少一件商品**"（针对直播）【外部核验】。"可对外展示"具体还要满足哪些条件，**尚未验证**，以后台提示为准。

### 第 3 步：开通短视频商品分享权益
- 手机路径：微信 → 发现 → 视频号 → 右上角人像 → 创作者中心 → 带货中心 → 账号身份 → 带货权限 → 选「视频带货」
- 前提：同时满足第三节的 3 个条件

### 第 4 步：发布时挂商品
发表视频或图片时，在信息编辑页下方点「链接或商品」→ 添加商品 → 从橱窗里选。

> ⚠️ 原资料称官方明确：**只能在发表时添加商品，已发布的内容不能补挂**。【原始资料】
>
> 🔍核验（2026-10-20）：
> - 微信开放社区的官方回复给出的流程是：发表视频 → 链接 → 商品 → 微信小店 / 选品中心 → **确认商品无误后再点发表**。商品是在发表环节挂上的（[微信开放社区](https://developers.weixin.qq.com/community/develop/doc/000ce213040ca01fac64870c061800)）。【外部核验】置信度：中
> - 第三方博客转述官方帮助中心：发布后可以改文字描述、短标题、封面、位置，**视频本身和所带的链接、商品不能改**，挂错只能删除重发（[海螺社](https://www.hailuoshe.com/blog/shipinhao-edit-after-publish)）。媒体报道过"三个月内的视频可以修改一次文案和封面"（[IT之家](https://www.ithome.com/0/858/776.htm)，年份未注明）。【外部资料】置信度：中
> - 结论：原资料的说法**与现有证据一致**，按"发表时必须挂好"执行。
> - 🆕 如果带货视频里有 AI 生成的内容，发表时还要**添加 AI 标注**（见 05）。

## 五、账号关联规则【外部核验】置信度：中

据官方支持页面的搜索摘要：
- 个体工商户店铺可关联视频号、公众号、服务号**各 1 个**
- 企业店初始各可关联 **5 个**，最多可提升到 **100 个**
- **1 个视频号只能关联 1 个微信小店或视频号小店**
- 操作路径：微信小店后台 → 店铺管理 → 关联账号 → 发起邀请

来源：[微信视频号带货账号体系](https://support.weixin.qq.com/cgi-bin/mmsupportacctnodeweb-bin/pages/UeQ967Q9tiftBN7r)

## 六、路线 B：达人带货【原始资料】

### 开通身份
微信 → 发现 → 视频号 → 右上角人像 → 创作者中心 → 带货中心 → 选「带货者 / 达人」身份

### 选品入口
- 手机：搜索「微信小店带货助手」服务号 → 菜单「去带货」→ 选品中心
- 电脑：微信扫码登录「微信小店带货助手」→ 左侧「选品」→ 选品广场

### 官方选品标准（原资料称原文）
1. 与账号内容契合度高
2. 销量好、下单转化高
3. 评分高、售后好
4. 与人设、内容风格契合

**具体做法**：按销量排序 → 看商品详情页的近 30 天销量 → 优先选销量呈上涨趋势的商品。

⚠️ 原资料提醒：分享评分差的商品会**拉低你的带货评分**；优选联盟会清退低分店铺的商品，清退后视频里的商品也会失效。

### 佣金与费用【外部核验】置信度：低-中
- 本次**没有检索到**优选联盟达人佣金比例、结算方式的官方完整规则。
- 媒体报道：商家技术服务费因类目而异，约 1%~5%（[数英](https://www.digitaling.com/articles/1422721.html)）；2025-03 推出"热招新商"权益，前 300 万元自营交易额的技术服务费率可降到 1%（[扬子晚报网](https://www.yzwb.net/news/community/202503/t20250304_188131.html)）。这些都是**商家侧费用**，不是达人佣金。
- 第三方文章提到"开通橱窗需缴 100 元保证金"，没有官方出处。【尚未验证】

## 七、你需要先确认的信息（原资料要求，仍然有效）

1. 营业执照是**企业**还是**个体工商户**？这决定开哪种店、银行账户是否必须对公。
2. 打算卖**什么品类**？这决定需要额外准备哪些类目资质。
