# 04 第一周 7 条视频骨架

> 来源：原始资料《04_第一周7条视频清单》，正文**原样保留**。核验意见放在文末。

---

**用法**：这 7 条是**通用骨架**。你现在还不知道品类也行——先按这个把"发布流程"跑通。
告诉我品类后，我把下面的 `【你的商品】` 换成你真实商品的完整口播稿。

**每条目标**：30~45 秒，120~180 字口播，真人出镜，加字幕。

---

## 第 1 条 · 自我介绍型（建立信任）

> 作用：让平台和用户知道你是干什么的，是带货账号的"地基"

**口播骨架**：
```
我是一个【你的身份，例：卖XX的/做XX的】。
做这个【几年/多久】了。
这个号主要分享三件事：
第一，【XX怎么挑】；
第二，【XX怎么用不出错】；
第三，【XX的坑我替你踩】。
有需要的可以关注一下。
```

**拍法**：站/坐在真实场景里（店、工作台、厨房），不用道具。
**挂商品**：先不挂，这条是养号+立人设。

---

## 第 2 条 · 避坑型（最容易涨粉）

> 作用：提供"有用"价值，官方明确"有用"是获得高流量的要素

**口播骨架**：
```
买【品类】之前，先说3个坑。
第一，别只看【XX】，要看【真正的判断标准】。
第二，【常见误区】，其实【正确做法】。
第三，【最容易踩的那个】。
我自己就踩过【第几个】，后来才知道要看【什么】。
```
```
结尾：想看具体怎么挑，关注我，下条讲。
```
**拍法**：对着镜头直接说，可以拿商品做参照。
**挂商品**：可挂可不挂。建议先不挂，把这条当纯干货。

---

## 第 3 条 · 痛点场景型（带货主力款）

> 作用：这是你的第一条真带货视频

**口播骨架**：
```
【人群】+【场景】的姐妹，看这条。
我自己就是【同样的问题】，【描述具体难受的细节】。
试过【XX】、【XX】，都不行。
后来用了【你的商品】，【1~2个可核实的具体卖点】。
```
```
需要的话我放在左下角了，今天有【优惠/赠品】。
```
**拍法**：**在痛点发生的真实场景里拍**（比如厨房、浴室、衣柜前）。
**挂商品**：✅ 挂。
**⚠️ 卖点必须是能查证的**——商品详情页写着什么就说什么，不许自己加"治疗""百分百"这类词。

---

## 第 4 条 · 开箱/细节展示型

**口播骨架**：
```
刚到的【商品】，拆给你们看。
【打开，展示实物】
先看【材质/成分/做工】——【具体描述】。
再看【细节部位】——【具体描述】。
到手价【价格区间】，这个价位我觉得【客观评价】。
```
```
想看哪款的可以在评论区问我。
```
**拍法**：手机架好俯拍或侧面，光线足，特写细节。
**挂商品**：✅ 挂。
**注意**：不要拆完就吹，要给**客观评价**（官方要求"真诚分享"）。

---

## 第 5 条 · 用法/教程型（价值最高，可长期复用）

> 官方明确："相关领域经验知识（使用技巧、适宜人群、适用场景、选购指南）"是高价值内容

**口播骨架**：
```
很多人【商品】都【用错了】。
正确做法是【第一步】。
然后【第二步】。
最后【第三步】。
这样【结果/好处】。
```
```
还有不懂的评论区问，我看到都回。
```
**拍法**：手部特写，一步一步做。
**挂商品**：✅ 挂。
**这条是复用性最强的**，可以做成系列（用法1/2/3）。

---

## 第 6 条 · 对比型（转化最高）

> 注意：只能和**你自己的旧方案**对比，不要跟别人家同类产品拉踩（那违规）

**口播骨架**：
```
之前我用的是【旧方案】，问题是【具体问题】。
换成【你的商品】之后，【具体变化】。
差在哪儿？【讲清原因，比如材质/规格/设计】。
当然它也不是完美的，【说一个无关痛痒的小缺点】。
```
```
要的看左下角。
```
**拍法**：左右对比，同角度同期拍摄。
**挂商品**：✅ 挂。
**⚠️ 红线**：绝对不能说"XX家的比这个差""全网最好"——见 `05` 号文件。

---

## 第 7 条 · 答疑型（拉互动 + 二次种草）

**口播骨架**：
```
上条视频有人问：【真实评论里的问题】，我用这条统一回。
第一，【问题1】——【回答】。
第二，【问题2】——【回答】。
第三，【最多人问的那个】——【回答】。
```
```
还有问题继续留言，我出下一条。
```
**拍法**：直接对镜头说，或边操作边答。
**挂商品**：✅ 挂（跟这条相关的商品）。
**关键**：问题必须是**真实评论**，不要自己编——编了被看出来就毁信任。

---

## 拍完这 7 条，你会得到什么

1. ✅ 跑通了"拍→挂商品→发布"完整流程（最重要）
2. ✅ 手里有了 7 条数据，能看出哪一类（避坑/场景/用法）你的号更适合
3. ✅ 官方要求的"公开发表视频 ≥ 10 条"这条接近达标（发满 10 条是开通带货权限的条件之一）

---

## 时间安排建议

| 天 | 动作 |
|---|---|
| 第 1 天 | 拍第 1 条（自我介绍），发出去 |
| 第 2 天 | 拍第 2 条（避坑） |
| 第 3 天 | 拍第 3 条（痛点场景，第一条带货） |
| 第 4 天 | 拍第 4 条（开箱） |
| 第 5 天 | 拍第 5 条（用法教程） |
| 第 6 天 | 拍第 6 条（对比） |
| 第 7 天 | 拍第 7 条（答疑）+ 回看 7 条数据的差异 |

每天只做这一件事，别贪多。

---

## 🔍核验与标注（本次补充）

1. **"发满 10 条是开通带货权限的条件之一"**：与官方《商品分享视频创作指引》的搜索摘要一致（见 02）。【外部核验】置信度：中-高
2. **"左下角小黄车""要的看左下角"**："小黄车"常用于指抖音购物车。视频号挂商品后，商品入口在画面里的具体位置和叫法，本次**未核实**【尚未验证】。拍之前先发一条测试视频，按实际位置改口播，避免引导语和画面对不上。
3. **第 3、4、6 条要求"挂商品"**：前提是已经开通短视频商品分享权益。按 07 的账号现状（关注者 10），走达人路线**还不满足 1000 有效关注**，只有开通并展示自营小店后才可能挂车。在此之前，这几条可以先按"不挂商品"发布，或者暂缓。【AI推断】置信度：中
4. **第 7 条"问题必须来自真实评论"**：当前账号新视频评论数为 0（见 07），暂时没有素材做这一条，可以放到后面再做。【AI推断】
