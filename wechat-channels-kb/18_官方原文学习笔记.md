### 2. 《视频号橱窗达人【发布低质量内容】实施细则》修订公告【原文，置信度：高；但这是 2022 年的修订公告，不是现行完整细则】

- 发布 2022-06-27，生效 2022-07-05。修订后把**短视频**纳入低质量内容。
- 原文"2.2 无实质内容"："视频号橱窗达人长时间未进行有效直播活动**或短视频时长较短、画质差、声音嘈杂等**"
- 违规示例原文：
  - (1) 画面模糊不清、黑屏（黑屏超过 3 秒以上）、剧烈晃、结尾突兀
  - (2) 视频环境杂乱，如：生产车间，货物间等
  - (3) 视频时长过短（**原文没给具体秒数**）
  - (4) 背景音乐声音过大，语音识别困难
  - (5) 无明确主题，无信息价值的纯文字
  - (6) **仅以文字或 PPT 播放形式呈现视频；以简单特效把多张图片拼凑在一起，无音效卡点技巧，仅是简单的图片展示**
- "2.5 观感不适"原文示例 (2)："**视频美颜、滤镜美化严重造成人物和商品失真的画面**"；(3)"视频封面文本遮挡画面过多、字数过多、影响观看"
- 直播类：无达人直播、无实质内容、**挂机录播**（例如播前一天的回放）、多开直播。

> **对 AI 的直接影响**：AI 把商品"美化"到失真，原文明确属于低质量（观感不适）。
> **注意原文限定词**：(5)(6) 有"无明确主题、无信息价值""仅以""简单特效""无音效卡点技巧"等限定。不能简化成"有字幕、有图片就违规"。

### 3. 《微信视频号原创声明及相关功能使用须知》【原文，置信度：高；页面未标日期】

- 原创标准原文："原创内容应为真人出镜实拍的作品，若无真人出镜，结合创作风格、主题定位、账号信息、垂直程度等可判断声明内容属于当前账号……作品需满足经系统智能比对，在视频号上无相似作品"
- **不得声明原创**的情形（原文节选）：
  1. 搬运或简易二次创作：添加遮挡物、转场、缩放、镜像、倍速、首尾帧、**字幕**、边框等，不产生信息增量
  2. 未经授权引用影视、音乐、动漫、游戏、体育赛事等内容
  3. **营销宣传内容："主要目的为推广、宣传和销售的内容，比如广告宣传、商家活动……"**
  4. 无意义或质量不高的内容："……视频时长不足 5 秒或者纯图片轮播"

> **对你的影响**【根据原文推断】：
> - **带货视频以销售为主要目的的，按原文不能声明原创**。创作分成计划只对原创视频展示广告，所以分成收入主要要靠**非带货的原创内容**（知识、教程、生活类）。
> - "不足 5 秒""纯图片轮播"的上下文是"不得声明原创"，**不是"不能发布"或"不能带货"的统一标准**。

### 4. 《微信小店优选联盟计佣与结算规则》（修订 2026-06-17，**生效 2026-06-26**）【原文，置信度：高】

**达人短视频怎么算佣金（第五部分）**
- 5.1.3：用户"通过带货者短视频中挂载的商品链接下单购买，且该商品的推广计划对该带货者生效中，该商品佣金计入该带货者"
- 5.1.4：用户通过你的渠道把商品**加购物车或收藏后，7 天内下单**，也算你的
- 5.1.1(3)：直播挂 A 商品，用户进店买了 B，且 B 的推广计划对你生效，B 也算你的

**不计佣**
- 5.2.1：商家结束推广计划后，任何渠道购买都不再计佣
- 5.2.2：**推广时有违规行为，该商品不予计佣**
- 5.2.3：加购、收藏超过 7 天才下单，不计佣

**怎么结算（第六部分）**
- 6.1：**售后期结束、没有退款或未决售后争议**后才结算
- 结算基数 = 用户实付金额 + 支付补贴 + 平台优惠（**商家优惠、运费不计入**）
- 6.3：佣金由商家设置并承担
- **6.4：必须"完成带货主体信息验证并开通微信支付商户号"，否则佣金退回商家，"已退回的佣金现在及将来均不会再进行结算"**
- 6.6：商家可以随时改佣金比例或结束推广，**达人要自己随时检查**；按用户下单时的比例算
- 6.7：商家下调佣金或关闭计划，**次日 0 时**生效
- 6.10：结算前退款的部分不结算
- 6.11：佣金要向商家开发票，或由商家代扣代缴税费（具体各方协商）

**推客模式（第四部分）**
- 2.4 定义原文："带货机构通过推客带货 api 接口开发并邀请带货者合作，在社群等场景进行商品推广的模式。该模式下带货者又称为'推客'"
- 也就是说，**推客要通过带货机构参与**，不是个人直接在平台注册就能做。
- 计佣时效（默认）：商品链接 30 天；短视频 / 直播间 / 公众号图文 3 天，首次下单后延长 30 天
- 同一商品、同一内容账号，佣金都计给**最近一次分享**的推客

> 🔍 本规则全文**没有出现"技术服务费"**。第 14 章提到的"2026 年带货者 10% 技术服务费"，在这份原文里**找不到依据**，继续标为未验证。

## 二、《大场直播系列》Vol.1~9（腾讯营销生意鹅，2026-08~10）

> 19 个链接是 9 篇文章的重复发布（同题文字一致）。文章**面向有日播基础、能调动品牌资源的商家**，案例数据都是 ADQ 广告归因口径，原文明确"不将结果归因于单个动作"。下面只摘你作为**小达人**能借鉴的部分。

| 篇目 | 原文核心句 | 你能借鉴的【根据原文推断】 |
|---|---|---|
| Vol.1 什么算大场 | 集中制造三个用户理由——"为什么值得进、为什么值得信、为什么现在买" | 每条带货视频都用这三问自查 |
| Vol.2 开播前定位 | "我们要借 ______ 这个节点，给 ______ 这类用户看 ______，这场优先把 ______ 做实。""主题讲工厂，镜头里就要尽快出现工厂" | 视频开头承诺什么，就要马上兑现；没有实物，就别承诺"亲测""开箱" |
| Vol.3 人升级 | "人升级真正要补的，是普通日播里原本缺少的故事、专业解释或信任关系""达人、KOC……更适合完成……真实使用、专业实测，或者站在某类用户的角度提出问题" | 达人的价值是**真实体验和第三方判断**，AI 生成的口播替代不了 |
| Vol.4 货升级 | 讲清"为什么值得买、为什么值得今天买、以及这一单到底值在哪里"；"赠品越贴近主品的真实使用场景，用户越容易看懂" | 讲商品时补齐这三个理由；赠品、价格**只说商家确认过的** |
| Vol.5 场升级 | "第一，素材必须来自真实现场。第二，主播要解释画面与商品有什么关系。""如果只有一张静态'工厂溯源'背景图……这可不算场景升级" | AI 生成的"工厂""现场"即使标注了，也不等于真实证据 |
| Vol.6 选达人 | 先看品类、客单价、人群三重匹配，"再看达人近期带货表现、带货评分、历史合作质量和履约风险。粉丝量可以参考，但不应该排在匹配之前""达人内容越像他平时会讲的东西，信任迁移才越自然" | 品牌挑达人看**垂直度和带货评分**。你要尽早固定一个品类，积累带货评分 |
| Vol.7 投流承接 | "大场节点 + 具体场景 + 产品利益"；进房三秒要看懂"这是什么场、今天和平时有什么不同、我现在下单能得到什么"；讲品四轮：痛点价值 → 实操细节 → 回答问题 → 权益 | 短视频标题和开头用"场景 + 产品利益"，比"福利""好物"具体 |
| Vol.8 投放 | "大场投放买到的是一次次流量探索，不是一个自动起量的结果" | 现阶段不投流，了解即可 |
| Vol.9 复盘 | "复盘要找的是值得复测的组合，而不是急着给某一个动作领功"；结论要写成可复测的动作 | 每周复盘写"下次把 XX 改成 XX 再看 XX 数据" |
