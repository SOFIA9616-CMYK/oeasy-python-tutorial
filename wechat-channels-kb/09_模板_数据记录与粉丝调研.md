## 三、粉丝群调研表（来自原始资料 Excel，原样保留）

> 原表说明：在各粉丝群里发给全体成员，建议**按周或按月**汇总。用途分别是：评价表提升参与感、意见表提升价值感、建议表提升归属感。
> ⚠️ 第 5 题会收集"是否方便联系"。在微信生态里，只能在微信内（群、私信）跟进，**不要借此引导用户去站外交易**（见 05 第三节）。【主观判断】

表头统一为：直播主题：____ 直播时间：____ 主播花名：____

### 1. 主观评价调研表
1. 对于这场直播你的感受如何？ A 很无聊 / B 无新意 / C 还不错 / D 有亮点
2. 对于这场直播有你喜欢和需要的商品吗？ A 没有 / B 不划算 / C 买过了 / D 太贵了
3. 对于这场直播主播的表现你满意吗？ A 不知道 / B 反感 / C 无感 / D 喜欢
4. 对于这样的调研参与你感兴趣吗？ A 不知道 / B 无聊 / C 还行 / D 可以
5. 你方便我们再根据此调研的反馈联系你吗？ A 不方便 / B 方便

结尾：感谢宝宝的参与，我们根据你的反馈正快马加鞭的改进呢~ 记得常来哦~ 此次宝宝增加的新积分（10）分

### 2. 主观意见调研表
1. 对于这场直播让您不喜欢的点有哪些？ 我的意见：____
2. 对于这场直播所销售的商品及价格，您不满意的点是什么？ 我的意见：____
3. 对于这场直播的主播有哪些不足之处是需要改进的？ 我的意见：____
4. 对于这样的调研参与你感兴趣吗？ A 不知道 / B 无聊 / C 还行 / D 可以
5. 你方便我们再根据此调研的反馈联系你吗？ A 不方便 / B 方便

结尾同上。

### 3. 主观建议调研表
1. 对于这场直播你的直观感受是怎样的？哪些点让你印象深刻？ 宝贵建议：____
2. 对于这场直播商品的选款和价格您满意吗？您有相关的好想法建议吗？ 宝贵建议：____
3. 对于这场直播主播的表现你满意吗？您觉得 TA 需要如何改进？ 宝贵建议：____
4. 对于这样的调研参与你感兴趣吗？ A 不知道 / B 无聊 / C 还行 / D 可以
5. 你方便我们再根据此调研的反馈联系你吗？ A 不方便 / B 方便

结尾同上。

> 🔍 评价表第 2 题的选项（没有 / 不划算 / 买过了 / 太贵了）全是负面或中性的，缺少"有，已购买"这类正向选项，统计时会有偏差。改不改由你决定，这里原样保留。【AI推断】
