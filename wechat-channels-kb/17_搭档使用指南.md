# 17 搭档使用指南：让 Chatbox 搭档帮你达成目标

> 给你自己看的。把下面这些话直接发给「视频号达人带货｜AI视频顾问」搭档就行。
> 搭档的工作方式写在 `00_先读这个.md` 的「目标教练模式」里。

---

## 第一次用：先让它记住你的情况

```
请记住我的情况：
方向：【品类】
一句话定位：我是【谁】，专门分享【什么人】的【什么问题】怎么解决
出镜方式：【露脸 / 声音+手部 / 声音+真实场景】
每周发布：【几】条
现在有效关注：【几】个
```

还没想好方向的话，就发：`帮我定方向和定位`

---

## 每周固定用法

| 时间 | 发给搭档 |
|---|---|
| 周一 | `给我本周 5 个选题，按 A/B/C 类分好` |
| 写稿时 | `把第 2 个选题写成分镜脚本，45 秒左右` |
| 发布前 | `帮我看看这条能不能发：`（贴上口播稿，或描述每个画面） |
| 发布 24h / 72h 后 | `记录数据：播放 X，点赞 X，评论 X，转发 X，带来关注 X` |
| 周日 | `本周复盘，这是 5 条的数据：……` |

---

## 其他常用指令

| 场景 | 发给搭档 |
|---|---|
| 看到一条爆款 | `拆解这条爆款：`（描述它的开头、画面、结构、数据） |
| 粉丝数变了 | `我现在有效关注 X 个，我能开通什么？` |
| 收到违规通知 | `我收到违规通知：`（贴通知原文） |
| 想偷懒走捷径时 | 它会直接告诉你哪些做法违反官方规则，这是正常的 |

---

## 用的时候注意

1. **数据要你自己贴给它**：它看不到你的视频号后台。
2. **热门话题、活动、佣金比例**它不知道，它会让你去后台查，这是对的。
3. **它说的和后台显示不一致时，以后台为准**，并把差异发给我，我更新资料包。
4. **搭档记忆有 100 条上限**（设置页显示 0/100）。快满时，让它"总结并精简记忆"。
